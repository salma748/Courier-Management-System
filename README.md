# Courier Management System

A desktop-based Courier Management System developed using C#, Windows Forms, and Oracle Database to automate shipment management operations.

## Features
- User Registration & Login
- Shipment Creation
- Shipment Tracking
- Courier Assignment
- Payment Management
- Delivery Confirmation
- Admin Dashboard
- Crystal Reports Integration

## Technologies Used
- C#
- Windows Forms
- Oracle Database
- ODP.NET
- Crystal Reports
